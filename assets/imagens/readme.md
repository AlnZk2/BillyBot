Coloque aqui a foto de perfil de cada NPC.

Duas formas de ligar a foto a um NPC:
  1. Nome do arquivo igual ao id da conversa: deuzebio.png, stefano.jpg ...
  2. Campo "avatar" no JSON: "avatar": "assets/imagens/Deuzébio Babosa.png"

Formatos aceitos: png, jpg, jpeg, webp, gif.
Use imagens quadradas (de 256x256 a 512x512) e com menos de 1 MB.
Depois de adicionar, reinicie o bot.
